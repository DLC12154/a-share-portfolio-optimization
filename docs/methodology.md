# 方法说明

## 研究问题

给定一个A股横截面Alpha分数，研究组合优化能否在现实交易约束下改善风险调整收益。项目比较全市场等权、同持股规模的Top 20/25等权、同换手约束的Top 20/25等权、Top 50等权、逆波动率加权和两类优化组合，避免把信号收益或持股集中度误归因于优化器。

## 时间与股票池

- 开发期：2020-01-02至2023-12-29。
- 时间外验证：2024-01-02至2025-12-31。
- 信号频率：每5个交易日。
- 股票池：Baostock `query_hs300_stocks(date=signal_date)`历史时点成分。
- 信号日筛选：当日交易、非ST、过去120个事件日至少120个交易日、20日日均成交额不低于3,000万元。

不按未来收益是否可得筛选股票。未来5日开盘收益仅用于事后诊断，不参与选股和权重计算。
管道先冻结点对点信号和目标权重，随后才附加未来收益用于RankIC评价。

## 因子

所有因子都在信号日收盘后计算，并在当日横截面内转为平均百分位排名：

- `momentum_20 = close_t / close_(t-20) - 1`
- `reversal_5 = -(close_t / close_(t-5) - 1)`
- `low_volatility_20 = -std(return, 20)`
- `low_turnover_20 = -mean(turnover, 20)`

复合分数为四个排名的等权平均。至少需要两个有效因子。

## 风险模型

使用前120个交易日的股票收益。若某只股票有效收益少于60个交易日，则从当期风险模型剔除。
通过最低覆盖要求后，风险窗口内剩余的少量缺失收益按0处理，代表停牌期间无价格变化，可能低估真实风险。

```text
Sigma_sample = sample covariance
Sigma_target = diag(Sigma_sample)
Sigma = (1 - delta) * Sigma_sample + delta * Sigma_target
delta = 0.20
```

协方差年化并执行特征值下限截断，避免优化器处理非半正定矩阵。
纯Alpha分配器的平均事前波动率约为12.51%，风险惩罚版本约为12.11%，22%的硬上限只在少数高波动时期起作用。

## 优化

### 纯Alpha分配器

```text
maximize    sum(score_i * w_i) - 1e-7 * sum(w_i^2)
subject to  sum(w_i) = 1
            0 <= w_i <= 5%
            sqrt(w' * Sigma * w) <= 22%
            0.5 * sum(abs(w_i - previous_i)) <= 50%
            0.8 <= sum(beta_i * w_i) <= 1.2
```

协方差在该版本只作为波动率上限，不进入目标函数。由于其平均事前波动率显著低于22%，实际组合通常集中在约21只高Alpha股票。因此该版本应称为“带风险、权重、换手和Beta约束的Alpha分配器”，不是均值-方差优化或风险平价。

### 风险与换手惩罚版本

在相同约束下，另一个策略把风险与换手加入目标函数：

```text
maximize    sum(score_i * w_i)
            - 0.50 * w' * Sigma * w
            - 0.01 * one_way_turnover
            - 1e-7 * sum(w_i^2)
```

该策略是在第一次审查2024–2025结果之后加入的透明扩展，因此其系数没有经过独立盲测。报告同时保留它和纯Alpha分配器，不把后验调整包装成预先设计的验证。

### 同规模与同换手对照

- `equal_top20`和`equal_top25`控制目标持股数量；
- `equal_top20_turnover_cap`和`equal_top25_turnover_cap`从上一期目标权重向新目标逐步调整，施加相同的50%单次单边换手上限；
- 换手受限版本会暂时保留旧持仓，因此实际平均持股数高于目标股票数。

候选集为Alpha前50只股票。旧的非候选持仓权重上限为其上一期权重，因此不会增加，但可能因换手限制没有立即清仓。

优化器使用SciPy SLSQP。若数值优化失败，只有当候选解满足全部约束时才接受；否则依次放宽波动率目标。所有日期均记录求解状态、有效风险约束和回退情况。

## 交易模型

目标权重在下一交易日开盘执行。停牌、开盘涨跌停和ADV容量会阻止或缩减订单。买入计划按资金上限统一缩放，而不是按股票代码顺序把现金先分给靠前股票。

成本：

- 佣金：3 bps，最低5元；
- 滑点：5 bps；
- 印花税：2023-08-28前卖出10 bps，之后5 bps；
- 不使用杠杆或融券。

## 评价

组合收益按每日收盘估值。评价指标包括CAGR、年化波动率、Sharpe、最大回撤、Calmar、相对动态等权基准的超额收益、跟踪误差、信息比率、换手、持股数量、现金权重、交易成本和阻塞订单。

除全局样本外区间外，还报告：

- 每个自然年的绩效；
- 每个自然年的Alpha RankIC；
- 将2024-09-10至2024-10-10及其后第一个交易日收益归零后的敏感性结果。

## 解释边界

优化组合在时间外区间没有跑赢同持股规模的Top 20/25等权组合。2025年复合信号Mean RankIC为-0.0060，风险惩罚组合CAGR为-0.12%，而全市场等权净基准为19.16%。因此最主要的发现是：复合信号在2024年有效、2025年失效；优化器没有形成跨年度稳定增量。项目价值在于数据时点处理、约束构造、交易执行和诚实的负向验证，而不是高Sharpe本身。
