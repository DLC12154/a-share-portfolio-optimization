# 组合优化研究结果

本次运行使用固定的四因子等权复合信号作为可复现Alpha基线。项目支持通过外部文件接入第二项目的滚动样本外预测分数。

## 组合设置

- 候选股票数：50
- 单票最大权重：5.0%
- 年化波动率约束：22.0%
- 单次最大单边换手：50.0%
- 风险模型窗口：120个交易日
- 协方差收缩系数：0.20
- 风险惩罚系数：0.50
- 换手惩罚系数：0.01

`optimized`只最大化Alpha并在硬约束内分配权重，`optimized_utility`额外把协方差风险和换手惩罚放入目标函数。后者是在已有结果审查后加入的透明扩展，不是预先注册的盲测策略。

## 解释

2025年复合信号Mean RankIC为-0.0060，同期风险惩罚组合CAGR为-0.12%，全市场等权净基准CAGR为19.16%。因此2024-2025的整体结果主要由2024年贡献，不能表述为跨年度稳定的Alpha。

时间外区间内，风险惩罚组合CAGR为19.27%、Sharpe为1.198、最大回撤为-10.41%。同换手约束的Top 25等权组合CAGR为20.34%、Sharpe为1.258、最大回撤为-9.60%。风险惩罚改善了纯Alpha分配器，但没有稳定超过同规模简单等权组合，不能只与包含约300只股票的等权基准比较。

排除政策行情窗口后，风险惩罚组合CAGR为7.30%、Sharpe为0.648；Top 25换手受限等权组合CAGR为7.50%、Sharpe为0.662。
