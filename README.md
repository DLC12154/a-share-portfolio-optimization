# A股多因子组合优化与交易约束研究

历史时点多因子选股之后的组合构建研究。项目检验同一个Alpha信号在等权、分数加权、逆波动率加权和风险约束优化下，能否在交易成本、权重上限和换手约束内形成更稳健的组合。项目重点是构建与交易约束分析，不把风险约束优化包装成稳定的Alpha来源。

## 核心结论

- 使用四因子等权复合信号：20日动量、5日反转、20日低波动和20日低换手。
- 2024年复合信号Mean RankIC为0.0710，Alpha表现明显；2025年降至-0.0060，信号方向失效。
- 2024–2025时间外验证中，风险惩罚组合扣成本后CAGR为13.31%，Sharpe为0.813，最大回撤为-13.61%；同期动态沪深300等权净基准为17.97%、0.925和-15.21%。
- 修正Beta定义后，优化组合相对基准只有最大回撤更小，收益和Sharpe均落后，不能再宣称风险调整表现优于基准。
- 同一区间的Top 20等权组合达到19.31% CAGR、1.179 Sharpe和-10.52%回撤；Top 25等权组合达到20.98%、1.280和-9.89%。在统一的当期合格成分股等权市场代理Beta约束下，优化组合没有战胜同持股规模简单组合。
- 整体表现主要由2024年贡献。2025年风险惩罚组合CAGR约-0.13%，而全市场等权净基准为19.16%，因此不能宣称复合Alpha跨年度稳定有效。
- 排除2024-09-10至2024-10-10政策行情影响后，风险惩罚组合CAGR仅0.38%、Sharpe0.097；等权基准为5.87%、0.435，Top 25换手受限等权组合为7.50%、0.662。
- 2024–2025是根据现有数据回溯划分的时间验证区间，不是预先注册的锁定OOS。

## 研究设计

### 股票池与信号

数据来自第一项研究冻结的Baostock历史数据：

- 291个五日历史成分快照，每次恰好300只股票；
- 481只历史成分股，731,507条后复权行情；
- 信号在交易日收盘后生成，下一交易日开盘执行；
- 未来收益只用于研究诊断，在信号和目标权重冻结后另行附加；
- 过滤ST、停牌、上市历史不足120个交易日及20日日均成交额低于3,000万元的股票。

Alpha默认由以下四个横截面排名字段等权合成：

| 因子 | 方向 |
|---|---|
| 20日价格动量 | 越高越好 |
| 5日价格反转 | 近期跌幅越大越好 |
| 20日波动率 | 越低越好 |
| 20日换手率 | 越低越好 |

项目也支持从CSV载入外部预测分数，后续可以直接接入第二项研究的滚动样本外预测结果。

### 风险模型

- 使用信号日前120个交易日收益估计协方差；
- 对样本协方差和对角协方差执行20%收缩；
- 特征值截断，保证协方差矩阵半正定；
- 使用当期全部合格历史成分股的等权收益作为市场代理，而不是只使用候选股票或旧持仓；
- 每只股票的Beta分子和分母使用同一个配对完整样本；
- 记录组合事前波动率和相对该等权市场代理的Beta。
- 纯Alpha分配器的平均事前年化波动率约15.50%，风险惩罚版本约15.37%；Beta约束在约95%以上的日期触及0.80下界，说明它对组合选择有实质影响。

### 组合优化

在每个信号日从Alpha前50只股票中构建组合，满足：

- 只做多；
- 权重和为1；
- 单票最大权重5%；
- 年化事前波动率不超过22%；
- 单次单边换手不超过50%；
- Beta位于当期合格成分股等权市场代理的1.0上下0.20；
- 不再买入已跌出候选池的旧持仓，但允许在换手限制内逐步退出。

项目实现两个版本：

- `optimized`：只最大化Alpha分数，并施加权重、波动率、换手和Beta硬约束。它更准确地说是“带约束的Alpha分配器”，协方差只用于限制风险。
- `optimized_utility`：在目标函数中加入风险惩罚和换手惩罚，让协方差真正参与权重选择。该版本是在初始结果审查后增加的透明扩展，不是事先注册的盲测策略。

若优化器无法求到满足约束的解，会依次放宽波动率目标并回退到逆波动率或等权配置，同时记录原因。

### 回测与交易

- 信号在收盘后生成，下一交易日开盘执行；
- 停牌或开盘接近涨停时不买入；
- 停牌或开盘接近跌停时不卖出；
- 使用前一交易日已知的20日平均成交额限制单笔交易；
- 单笔不超过20日平均成交额的5%；
- 佣金3 bps，单笔最低5元；
- 滑点5 bps；
- 卖出印花税按2023-08-28前后分别使用10 bps和5 bps；
- 买盘按资金上限等比缩放，避免按股票代码顺序分配剩余现金；
- 不使用杠杆，不假设个股融券。

## 已知限制

- 没有可靠的逐日历史行业分类，因此本次运行未做行业中性化；项目三没有伪装成已经完成行业约束。
- 历史成分只在五日调仓日取快照。
- Beta使用当期全部合格历史成分股的等权收益，不是对官方沪深300指数收益的回归。
- 120日风险窗口中仍缺失的少量收益按0处理，可能低估停牌风险。
- 后复权合成价格不等同于真实逐笔成交价格。
- 没有模拟100股整手、红利税、盘口排队、永久市场冲击和真实借券成本。
- 换手限制使用上一期目标权重计算，实际交易受阻会令下一期实际持仓偏离目标。
- 2024–2025区间已经被原始研究观察过，不能表述为完全盲测。
- 风险惩罚版本在看过初版验证结果后加入，不能表述为其参数在2024–2025上得到盲测确认。
- 换手受限Top 20/25组合会暂时保留旧持仓，因此实际平均持股数高于目标股票数；它们控制的是目标换手，不等于全程只持有20或25只股票。
- 优化组合没有稳定跑赢同持股规模的Top 20/25等权组合，结果应解释为风险分配和交易约束分析，而不是优化器有效性证明。

本项目用于量化实习展示和方法复盘，不构成投资建议。
